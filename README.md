# Back-End Development and APIs projects

Five freeCodeCamp certification practice projects, implemented with AI assistance. Starter assets and seeded data: freeCodeCamp/back-end-development-and-apis.

## Run locally

Run `npm ci` in the project folder, then `npm start`. For the prime checker, import `isPrime` from `index.js`.

The family movie API uses freeCodeCamp's public fictional test fixtures. These are intentionally excluded from this repository. Before running that project, run `node seed-data.mjs` inside its folder to download the official fixtures. Set `JWT_SECRET` to a locally generated random secret and `PORT=3000` in your local environment (or an untracked `.env` file).
